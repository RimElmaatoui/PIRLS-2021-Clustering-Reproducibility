# Aggregate results

This directory contains aggregate, non-individual outputs retained as a transparent record of the analyses reported in the manuscript.

- `primary_analysis/`: common-space metrics, cluster sizes, reading summaries, and external-variable tests.
- `stability/`: pairwise and summarized adjusted Rand indices across random seeds.
- `pca_baseline/`: PCA+k-means geometric, stability, and external-validation comparisons.
- `imputation/`: preprocessing audit and partition sensitivity across missing-data treatments.
- `ablation/`: hyperparameter-screening configurations and results.
- `cross_country/`: harmonized country-level comparisons.
- `computational_efficiency/`: timing, memory, environment, and scalability summaries.

Raw data, student identifiers, individual assignments, and latent matrices are deliberately excluded.
